# Пахта йиғими — ArcGIS Experience Builder widget

Built widget (ExB 1.14 / ArcGIS Enterprise 11.3). Add it in Experience Builder as a custom widget by URL:

https://tenxengineer.github.io/uzgps-cotton-widget/manifest.json

The data comes from the portal API (`apiUrl` in the widget settings, default https://api-gps.uzspace.uz) and needs an ArcGIS Enterprise sign-in.
